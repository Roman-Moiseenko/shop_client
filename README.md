# Клиентский сайт на Nuxt для CRM Shop.DTO
Шаблон клиентского сайта для работы с API

## Структура 
Базовый шаблон содержит
- компоненты страницы Page
- Заголовок
- Подвал


## Страницы Page
Страницы Page двух типов - simple тогда публикуется html контент и widget_based - состоит из блоков виджетов, api передает только данные,
сами виджеты рендерит компонент renderer\Widget.vue Ю который по slug ищет соответствующий компонент
Страницы могут иметь отличный от Default шаблон
Шаблоны хранятся в page-template
